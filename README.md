# 💰 SnapSave — Full-Stack Expense Tracker

**Smart expense analyzer for PhonePe UPI users**

Know where your money actually goes. Upload your PhonePe statement PDF, get instant spending insights, set savings goals & category budgets, and receive AI-assisted recommendations — all backed by a secure Express + MongoDB backend.

> Built with React 18 + Vite + Tailwind CSS + Express.js + MongoDB Atlas + Gemini AI

---

## ✨ Features

### Frontend (React SPA)

- 📊 **Dashboard** — Real-time totals (spent / received / savings rate), category pie chart, daily bar chart, computed spending alerts, personalized saving tips, and financial health score
- 🔍 **Deep Insights** — Top 10 merchants table, category breakdown with percentages, repeated small-expense detection, time-of-day heatmap, and dynamically computed potential savings
- 🎯 **Goals & Budgets** — Monthly savings goal, per-category budget creation & deletion, real spending merged from transactions, and dynamic achievements
- 📤 **Upload** — Drag-and-drop PhonePe PDF upload, server-side parsing, auto-categorization into 8 categories, and dashboard synchronization after upload
- 🔐 **Authentication** — JWT-based registration, login, protected routes, token verification, and automatic logout on unauthorized responses
- 🤖 **AI Recommendations** — Gemini-powered financial recommendations using the user's spending context
- 🔄 **AI Retry Handling** — Temporary Gemini service failures can be retried automatically
- ❤️ **Health Check** — `GET /api/health` endpoint for monitoring
- 🧪 **Automated Testing** — Jest test suite covering backend functionality and Gemini provider behavior

### Analytics Engine (`src/utils/analytics.js`)

- `calculateTotals()` — Total spent, received, net, and savings rate
- `getCategoryBreakdown()` — Category-wise amounts with percentages
- `getDailySpending()` — Dynamic daily spending derived from actual transaction dates
- `getTopMerchants()` — Top 10 merchants by total spending with count and average
- `getRepeatedExpenses()` — Detects merchants with repeated small transactions
- `getTimePatterns()` — Extracts transaction timing patterns
- `getWasteAlerts()` — Identifies repeated spending patterns using transaction history
- `generateSavingTips()` — Generates personalized saving tips based on spending behavior
- `calculateFinancialScore()` — Calculates a 0–100 financial score with grade and label

### AI Recommendation Layer

🚀 Getting Started
Prerequisites
- Node.js v18+ and npm
- MongoDB Atlas account or local MongoDB instance
- Gemini API key for AI recommendation functionality
1. Clone the Repository
git clone https://github.com/Akshaykumar-V/project-sanp-save.git
cd project-sanp-save

2. Setup Backend
cd backend
npm install

Create a backend/.env file:
PORT=5000
MONGODB_URI=mongodb+srv://<username>:<password>@<cluster>.mongodb.net/snapsave?retryWrites=true&w=majority
JWT_SECRET=your_jwt_secret_key_here
JWT_EXPIRE=7d
GEMINI_API_KEY=your_gemini_api_key_here

Replace:
- <username> with your MongoDB username
- <password> with your MongoDB password
- <cluster> with your MongoDB cluster
- your_gemini_api_key_here with your Gemini API key
URL-encode special characters in the MongoDB password if required. For example, @ becomes %40.

Start the backend:
npm run dev

The backend runs on:
http://localhost:5000

For production:
npm start

3. Setup Frontend
From the project root:
npm install

Create a root .env file:
VITE_API_URL=http://localhost:5000/api

Start the frontend:
npm run dev

The frontend runs on:
http://localhost:5500

4. Build for Production
npm run build

Preview the production build:
npm run preview

AI Recommendations
The AI recommendation functionality uses the financial context already processed by SnapSave.
The backend:
1. receives the user's financial context
2. validates the request
3. creates the AI request
4. sends the request to Gemini
5. returns the generated recommendation
6. retries temporary retryable failures when appropriate
7. returns the original error when the failure is not retryable
Gemini configuration is provided through:
GEMINI_API_KEY=your_gemini_api_key_here

📱 How to Upload a PhonePe Statement
1. Open the PhonePe app.
2. Open your profile.
3. Go to Transaction History.
4. Select the required date range.
5. Choose Download Statement.
6. Select PDF format.
7. Save the PDF.
8. Open SnapSave.
9. Login or create an account.
10. Open the Upload page.
11. Drag and drop the PDF or browse for it.
12. SnapSave parses the transactions.
13. Transactions are categorized and stored.
14. Dashboard and analytics update using the uploaded data.
Don't have a statement PDF? Use the sample/demo data option to explore the application.

🎯 Core Product Principle
SnapSave should not automatically label a transaction as "waste" based on one payment.
The intended approach is:
Transaction
    ↓
Understand entity
    ↓
Build personal spending history
    ↓
Detect patterns
    ↓
Compare with user's own history
    ↓
Generate evidence-based insight
    ↓
Use AI to explain or recommend

Unknown does not mean unnecessary.
Known does not automatically mean good.
The system should use evidence and the user's own spending history before making stronger observations.
AI is intended to explain and assist with the financial context generated by SnapSave, not replace the underlying data and analytics.
